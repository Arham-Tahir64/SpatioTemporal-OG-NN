              At the input, channel selection chooses an actual history slot and
              evidence plane. At the output, it chooses one of four toy forecast
              horizons. Hidden learned channels are unavailable, so
              channel-index selection is disabled there; the image instead
              demonstrates convolution and resampling of a selected evidence
              plane. Changing the temporal comparison also changes the toy
              predictor's centroid-velocity aggregation; it does not run a
              ConvLSTM or Transformer.

            This patch performs real gradient descent on independent cell
            logits: dBCE/dz = p − y; z ← z − η(p − y). It is not U-Net training
            and has no shared weights or generalization. The step uses a sum
            loss; displayed NLL is its valid-cell mean. Patches are frozen
            snapshots; edit the scene, then capture again. The real model
            averages valid cells per horizon, gives future horizons equal
            weight, and adds 0.25 × current-head loss.

          What do these layers mean?
          

            Static = structure truth for teaching. Actor outlines include
            stopped vehicles. Prediction = binary actor probability, not
            semantic class or free space. Flow = optional backward ground-truth
            displacement for a unique supported correspondence. Velocity = toy
            track estimate. Errors = TP/FP/FN/TN at the selected threshold.
            Missing supervision is hatched.
          

          

            Correct negative cells mean no selected actor, never certified safe
            free space. A wall may be a true negative for this actor-only task.
          

        

        

          Forecast limitations
          

            Hits are associated using synthetic object IDs and known box sizes.
            Motion comes from hit-centroid histories. Architecture options
            switch toy aggregation rules. No neural weights are loaded. This is
            not an implementable sensor-only benchmark baseline; oracle
            assistance is deliberate and visible.
