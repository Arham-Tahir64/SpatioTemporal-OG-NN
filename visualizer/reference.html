          What is actually being simulated?
          

            A deterministic 2D scene with a moving car, a crossing pedestrian, a
            stopped vehicle and two structures. Rays stop at the first rectangle
            they intersect. Forecasts use a deliberately imperfect analytic
            motion rule, not a neural network. The small sensor demo omits 3D
            heights, noise and full CARLA geometry. Toggles change this toy
            scenario; they are not simulator-semantic inputs available to the
            real model.

          Why alignment does not stop moving objects
          

            Transforming coordinate frames changes how a physical location is
            expressed; it does not rewind an actor. After compensation,
            buildings overlap across all six frames, but a moving car traces its
            actual motion. Turn compensation off in the scene to see ego-induced
            trails added to both. Future labels also stay in E₀; using a future
            ego frame would silently change the prediction task.

          Where would cameras enter?
          

            In v1, RGB is only a demo panel. A later camera branch would extract
            image features, estimate a depth distribution, unproject pixels with
            camera intrinsics, transform points with extrinsics, then lift/splat
            features into BEV before fusion. One pixel is a ray, not a known BEV
            position: depth uncertainty matters. BEVFormer-style attention is
            another option; neither camera branch is part of the initial LiDAR
            model.

          What is a feature map?
          

            Each channel is a learned spatial response, not necessarily an
            interpretable object label. A 3×3 convolution mixes nearby cells and
            all input channels. Downsampling expands context; decoder upsampling
            and skip connections recover localization. The 24 input channels
            preserve six time slots × four evidence channels. The first stacked
            convolution mixes time immediately—there is no separate recurrent
            block in the v1 model.
          

          

            Each block uses two padded 3×3 convolutions, GroupNorm with 8 groups
            and SiLU. Bilinear upsampling uses align_corners=False. The four
            output channels are independent future Bernoulli logits; applying a
            softmax across horizons would be incorrect.

A separate supervision branch

            
CARLA actor truth at t+h
  → box-local corners → world → fixed E₀
  → clip to ROI → polygon/cell intersection
  → union of supported non-ego actors
  → binary target Yₕ + independent validity Mₕ

            

              Include stopped and input-occluded actors. Exclude ego by
              identity. A cell unseen by LiDAR can still have a valid simulator
              label. Missing truth is invalid supervision, not an empty target.
            

            

              At 20 Hz, histories use tick offsets −20, −16, −12, −8, −4, 0;
              future truth uses +10, +20, +40, +60. Join exact frame IDs; keep
              future truth inaccessible to model inputs.

          IoU = TP/(TP+FP+FN). Precision asks how many predicted positives were
          right; recall asks how many true positives were found. Brier and NLL
          use unthresholded probabilities. Try changing only the threshold:
          overlap changes, probability scores do not.
        

        

          How the real evaluation will differ
          

            Report every horizon (0.5/1/2/3 s), average precision, Brier, NLL
            and reliability with support counts. Use fixed grouped episode
            splits, calibration separate from test, moving/pedestrian/occlusion
            slices, three final training seeds and paired scenario-group
            bootstrap intervals. Compare learned persistence and causal
            sensor-derived constant velocity; identify stronger-input oracle
            baselines separately. Undefined ratios are null, not perfect scores.
            The sandbox uses all 16,384 cells as valid and clamps NLL
            probabilities to [10⁻⁶, 1−10⁻⁶].
          

          

            The eventual speed goal is 5 Hz and p95 pipeline <200 ms on the
            actual Windows hardware. No latency, accuracy or model-memory
            measurements exist yet.
